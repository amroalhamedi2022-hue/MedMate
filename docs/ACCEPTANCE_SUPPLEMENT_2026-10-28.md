- **Production change:** `BoundedEvidenceIndexCache` now assigns a monotonically increasing request epoch when a search begins. `StudyBrain.search` passes that epoch to index creation. A search already superseded at the cache boundary may finish its local retrieval, but cannot repopulate or replace the shared chapter index after a newer request has begun. A matching existing immutable index may still be reused safely; oversized stale requests cannot clear a newer entry.
